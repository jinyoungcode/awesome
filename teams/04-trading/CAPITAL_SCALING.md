> 대표 결정 (2026-11-23): **처음에는 테스트용으로 10만원부터 시작합니다(→ D-031로 15만원으로 변경). 프로그램이 안정되면 금액을 점점 늘리는 것이 목표이고, 설계는 1천만원 이상도 운용할 수 있게 합니다.**
> **D-031·D-032 (2026-11-24): T0 시작 자금은 15만원(전액 운용, 예비금 없음)이며 모의투자 시작금도 15만원입니다.** 주문 목표 = (15만원 + 실현 순손익) ÷ 5 = 3만원, 1주 예외 가격 상한 4.5만원(30%), 1건 손실 상한 3,000원(2%), 최종 손절 3만원(−20%).

## 3. 1천만원 이상을 위한 설계 원칙 (지금부터 코드에 반영)

1. **모든 수량·금액 한도는 비율(%)로** 정의합니다. 절대금액(원)으로 하드코딩하지 않습니다. 단계표의 원 단위 값은 설정 파일에만 둡니다.
2. **유동성 상한**: 1건 주문 ≤ 최근 20일 평균 거래대금의 1% (데이트레이딩은 직전 5분 거래대금의 5%). 자본이 커지면 이 상한이 먼저 걸립니다.
3. **용량 점검**: 자본이 1억원에 가까워지면, 유동성 상한 때문에 깎인 주문 비율이 10%를 넘는지 확인합니다. 넘으면 유니버스를 넓히거나 전략을 추가합니다.
4. **소수점 거래 (D-019, D-021)**: T0(15만원) 단계는 정수 주문으로 운용하고, 고가주는 1주 예외 매수로 담습니다. 소수점은 증권사 API 지원이 확인되면 적용합니다(현재 KIS API 근거 없음, COMMON_SPEC §15.6). 소수점이 켜지더라도 데이트레이딩에는 쓰지 않습니다(가격 지정 불가, 회차 일괄 체결).
5. **해외주식 세금 충당 (D-034)**: 해외주식 예상 납부세액(양도소득세)은 주문 가능 현금과 재투자 재원에서 뺍니다. 같은 과세연도 실현손익과 연 250만원 기본공제로 충당금을 갱신하고, 다른 계좌 자료가 없으면 잠정치로 표시합니다. 사이징의 `cash_avail`과 D-005 주문 목표 계산에 쓰는 실현 순손익에도 이 충당금을 반영합니다.

## 6. 실전 기간 중 모의투자 병행 운용 (대표 지시, 2026-11-27)

T0부터 실계좌로 운용하는 동안에도 **모의 계좌에서 같은 전략을 계속 돌립니다.**

| 항목 | 내용 |
|---|---|
| 목적 | ① 같은 날 같은 신호의 **실전과 모의 체결 차이**(체결 여부, 체결가, 슬리피지) 측정 ② 실계좌에 아직 넣지 않은 전략(S03, 이후 데이트레이딩 D 시리즈)의 모의 검증 ③ 점검용 주문(T_TECH)이 필요할 때 실계좌 대신 모의에서 시험 |
| 운용 전략 | 실전과 같은 S02 + 실전 전 단계 전략(S03 등). 점검용 주문은 모의에서만(D-027) |
| 운용 금액 | **모의 계좌 주문 가능 금액 전액** (대표 결정, D-049). 주문 목표·1주 예외·손실 한도는 그 금액 기준 비율(D-044). 실전과 수량은 1:1로 비교하지 않습니다 |
| 분리 원칙 | 모의·실전은 **계좌, API 키, 상태 파일, 장부, 주문 ID 접두어를 모두 분리**합니다. 한 프로세스가 두 계좌에 주문하지 않게 합니다(프로그램팀). 손실 한도·킬스위치는 계좌별로 따로 적용합니다 |
| 매일 비교 (일지) | ① **신호 일치**: 같은 날 실전·모의 S02 신호의 종목·방향·사유코드가 같은지 (수량·금액은 운용 금액이 달라 비교하지 않음. 실전에서 1주 예외 한도 등으로 빠진 종목은 '실전 사이징 제외'로 따로 표시) ② **체결 여부**: 같은 종목 주문의 체결/미체결 일치 ③ **슬리피지(비율)**: 청산은 당일 시가 대비, 진입은 지정가 대비 % 차이 ④ 각 계좌 장부 대사 결과 |
| 증액 조건과의 관계 | T0 → T1 증액 판단의 체결·슬리피지 기준(PAPER_3DAY_CHECK §3)은 **실계좌 기준**입니다. 모의 결과는 비교 참고용입니다 |
