# S01 — 추세 돌파 스윙 (TF-BRK) 전략 명세서 v0.1

| 항목 | 내용 |
|---|---|
| 상태 | `SPEC` (명세 완료 → P2 백테스트 대기) |
| 버전 | v0.1 / 2026-11-23 |
| 담당 | 전략 리서처(설계), 포지션 매니저(사이징) |
| 상속 | `COMMON_SPEC.md` 전체 |
| 슬리브 비중(제안) | 총자산의 30% |
| 유형 | 추세추종, 롱온리, 손익비형 (예상 승률 35~45%, 평균 이익/평균 손실 2배 이상) |
| 예상 보유기간 | 10~60거래일 |

## 1. 가설 (왜 돈이 되는가)
기관·외국인의 대규모 매집은 며칠이 아니라 수주에 걸쳐 일어납니다. 거래대금이 실린 60일 신고가 돌파는 이런 수급 변화를 보여주는 가장 단순한 신호입니다. 추세는 생각보다 오래 갑니다. 손실은 ATR 손절로 작게 끊고, 이익은 트레일링 손절로 끝까지 따라가 **손익비**로 돈을 법니다. 시장 국면이 하락이면 돌파의 대부분이 실패하므로 국면 필터로 진입을 막습니다.

**실패하는 국면**: 지수 박스권이 길게 이어지는 장(가짜 돌파가 반복되어 연속 손절), 급락 후 V자 반등 초기(국면 필터가 늦게 켜짐).

## 3. 진입 규칙 (T일 종가 확정 후 판정)

종목 i가 아래 조건을 **모두** 만족하면 진입 후보입니다.

| # | 조건 | 수식 |
|---|---|---|
| E1 | 유니버스 | i ∈ U_T |
| E2 | 시장 국면 ON | regime_on(market_i, T) |
| E3 | N일 신고가 돌파 | C_T > HH(High, N)_T |
| E4 | 중기 정배열 | SMA(C,50)_T > SMA(C,200)_T |
| E5 | 거래대금 동반 | 거래대금_T ≥ k × ADV20prev_T (k=1.0이면 항상 참) |
| E6 | 과열 추격 금지 | RET(1)_T ≤ 0.15 |
| E7 | 변동성 범위 | 0.015 ≤ ATRpct(20)_T ≤ 0.08 |
| E8 | 미보유 | S01을 포함한 어떤 슬리브도 i를 보유하지 않음 |
| E9 | 재진입 대기 | S01에서 i를 마지막으로 청산한 날로부터 5거래일 경과 |

**순위**: 후보를 `RET(120)_T` 내림차순으로 정렬합니다(동점은 종목코드 오름차순).
**선정**: 순위대로 `min(max_new_per_day, max_positions − 현재 보유 수)`개를 고릅니다. 사이징 결과 수량이 0이면 다음 순위로 넘어갑니다.

## 4. 진입 주문

```
L      = tick_floor( C_T(raw) × (1 + gap_cap) )         # 주문유형 LOO
stop_ref = max( L − m × ATR(20)_T ,  L × (1 − max_stop_pct) )
Q      = COMMON_SPEC §10 (Q_risk, Q_weight, Q_cash, Q_liq 중 최솟값; Q_slot 미사용)
```
- 체결 시 (백테스트): `fill = Open_{T+1} × (1 + slip)` (Open_{T+1} ≤ L 일 때만)
- 체결 후 초기 손절가: `init_stop = max( fill − m × ATR(20)_T , fill × (1 − max_stop_pct) )`
- R = fill − init_stop

## 5. 보유 중 손절가 갱신 (매 T일 종가 후)

```
HC   = 진입일 이후(진입일 포함) 최고 종가
mult = trail_atr_mult           if regime_on(market_i, T)
       trail_atr_mult_regime_off otherwise
trail_T = HC − mult × ATR(20)_T
stop_T  = max( stop_{T−1}, trail_T )      # 손절가는 절대 내려가지 않습니다 (stop_0 = init_stop)
```

## 6. 청산 규칙 (T일 판정 → T+1 `MOO`)

판정 순서대로 확인하고, 처음 맞는 사유 하나로 청산합니다.

| 순서 | 코드 | 조건 |
|---|---|---|
| 0 | X_ADMIN/X_KILL | COMMON_SPEC §8 |
| 1 | X_STOP | C_T ≤ stop_T (방금 §5에서 갱신한 값) |
| 2 | X_TIME | 보유일수 ≥ 15 **그리고** C_T < 진입 체결가 (15일이 지나도 손실 중이면 정리) |

- 목표가(익절가)는 따로 두지 않습니다. 트레일링 손절이 익절 역할을 합니다.
- 장중 손절 감시는 없습니다(종가 판정 → 다음 날 시가 집행). 갭하락은 그대로 손실로 받아들이고 백테스트에 반영됩니다.

## 7. 검증용 예제 (프로그램팀 단위 테스트용)

**조건**: E_total = 30,000,000원, KOSPI 종목, C_T = 52,300원(원주가=수정주가), ATR(20)_T = 1,840원, ADV20_T = 80억원, S01 슬리브 가용현금 4,000,000원, m = 2.5, slip = 0.10%

| 단계 | 계산 | 결과 |
|---|---|---|
| 지정가 | tick_floor(52,300 × 1.03 = 53,869) — 호가단위 100 | **L = 53,800** |
| stop_ref | max(53,800 − 4,600, 53,800 × 0.90 = 48,420) | **49,200** |
| Q_risk | floor(150,000 / 4,600 = 32.6) | 32 |
| Q_weight | floor(3,000,000 / 53,800 = 55.8) | 55 |
| Q_cash | floor(4,000,000 / (53,800 × 1.00015) = 74.3) | 74 |
| Q_liq | floor(80,000,000 / 53,800 = 1,486.99) | 1,486 |
| **Q** | min | **32주** (주문금액 1,721,600원 ≥ 200,000원) |
| T+1 시가 52,900 ≤ L → 체결 | 52,900 × 1.001 | **fill = 52,952.9** |
| init_stop | max(52,952.9 − 4,600 = 48,352.9, 47,657.61) | **48,352.9**, R = 4,600 |

**트레일링 예**: 이후 최고 종가 HC = 61,000원, 그날 ATR = 2,000원, 국면 ON → trail = 61,000 − 6,000 = 55,000 → stop = max(48,352.9, 55,000) = **55,000**. 다음 날 C_T = 54,800 ≤ 55,000 → X_STOP, T+1 시가 청산.

## 8. 백테스트 변형 (P2에서 함께 보고, 채택은 기본형 우선)
- V1: 청산을 다음 날 시가 대신 **당일 종가 단일가**(15:20~15:30)로 집행 (신호를 15:15 가격으로 근사)
- V2: 장중 하드 손절 (저가 ≤ stop이면 min(시가, stop) × (1 − slip)로 체결)
- V3: 국면 OFF 시 전량 청산

## 9. 벤치마크
KOSPI200 TR. 그리고 같은 유니버스에서 **무작위 진입 + 같은 청산 규칙**으로 1,000회 몬테카를로 (`EVALUATION.md` §3.4).

## 10. 모의투자(P3) 통과 기준 — D-002 이행
공통 기준은 `EVALUATION.md` §3.3을 따르고, S01에만 해당하는 사항은 다음과 같습니다.

| 항목 | 기준 |
|---|---|
| 기간 | 8주 이상, **체결 거래 ≥ 10건**을 채울 때까지 (최대 12주) |
| 중점 확인 | ① 장전 동시호가 LOO 주문: 지정가 초과 갭상승 종목이 미체결 처리되는지 ② 트레일링 손절가가 매일 백테스트와 원 단위까지 같은지 ③ 국면 OFF 전환 시 트레일링 배수가 2.0으로 바뀌는지 |
| 체결 여부 일치율 | ≥ 95% (LOO) |
| 표본 해석 | 거래 수가 적어 승률·손익비는 **판정에 쓰지 않습니다**(참고 지표). 손익비형 전략은 8주 동안 손실이 날 수 있는 것이 정상입니다 |

## 11. D-005 모드 (10만원 모의·소액 단계) 관련 — COMMON_SPEC §15 우선
- 10만원 단계에서는 주문 목표가 약 2만원이라, 이 전략의 주요 대상(국내 대형주, 지수 ETF 등 1주 2만원 초과)을 대부분 살 수 없습니다. 또 보유기간이 D-003의 우선 검증 범위(1~5거래일)보다 깁니다. 그래서 **이 전략은 자본 T1(100만원) 이상 단계에서 모의투자를 시작**하는 것으로 미룹니다. P2 백테스트는 일정대로 진행합니다.
- 그 단계에서도 사이징은 COMMON_SPEC §15.1을 우선 적용하며, 자본 단계가 바뀔 때 다시 정합니다(`CAPITAL_SCALING.md`).
