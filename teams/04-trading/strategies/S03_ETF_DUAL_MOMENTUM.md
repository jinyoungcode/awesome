## 1. 가설
주가지수는 장기 추세를 보입니다(시계열 모멘텀). 하락 추세에서 주식을 피해 채권이나 현금으로 옮기면 수익률은 비슷하게 지키면서 큰 낙폭을 피할 수 있습니다. 1년 이상 이어지는 약세장(2008, 2011, 2018, 2022년)에서 이 효과가 컸습니다. 규칙이 단순하고 파라미터가 거의 없어 **과최적화 위험이 가장 낮은 전략**입니다. 그래서 계좌의 Core 역할을 맡깁니다.

**실패하는 국면**: 급락 후 급반등(2020년 3월처럼 신호가 늦게 바뀌어 반등을 놓침), 주식과 채권이 함께 떨어지는 금리 급등기(2022년).

## 3. 파라미터

| 이름 | 기본값 | 그리드 | 비고 |
|---|---|---|---|
| `trend_ma` | 200 | {150, 200, 250} | **튜닝 1** (유일한 튜닝 대상) |
| `mom_lookbacks` | [63, 126, 252] | 고정 | 3·6·12개월 평균 모멘텀 (여러 기간을 평균해 기간 민감도를 줄임) |
| `rebal_band` | 0.05 | 고정 | 목표와 현재 비중 차이가 5%p 이하면 매매 생략 |
| `rebal_freq` | 월말 | 고정 | 매월 마지막 거래일 신호 → 다음 달 첫 거래일 집행 |

## 4. 신호 (매월 마지막 거래일 T, 종가 기준. ETF는 분배금을 재투자한 TR 가격 사용)

```
for each asset a in {A, B, SAFE}:
    M_a = ( RET(63)_T + RET(126)_T + RET(252)_T ) / 3

risk_on(a) = (M_a > 0) and (C_a,T > SMA(C_a, trend_ma)_T)     # a ∈ {A, B}
safe_on    = (M_SAFE > 0)

target weight (슬리브 기준):
  w_A    = 0.5 if risk_on(A) else 0
  w_B    = 0.5 if risk_on(B) else 0
  w_rest = 1 − w_A − w_B
  w_SAFE = w_rest if safe_on else 0
  w_CASH = w_rest − w_SAFE
```

## 5. 주문 (T+1 = 다음 달 첫 거래일)

```
for a in {A, B, SAFE}:
    cur_w = 보유평가액_a(C_T) / E_s
    if |w_a − cur_w| ≤ rebal_band and not (w_a == 0 and cur_w > 0):   # 비중 0 전환은 밴드와 무관하게 전량 매도
        skip
    target_qty = floor( w_a × E_s × (1 − 0.005) / C_a,T )   # 0.5% 현금 버퍼
    delta = target_qty − cur_qty
매도(delta<0) 먼저 MOO → 매수(delta>0) MOO
```
- 체결가: T+1 시가 × (1 ± slip_ETF)
- **손절 규칙 없음**. 월 1회 신호가 위험 관리 역할을 합니다. 단, 리스크관리실 킬스위치(X_KILL)는 적용됩니다.
- 사이징: COMMON_SPEC §10 대신 위 식을 씁니다. ETF는 1종목 10% 한도 대상이 아닙니다(분산된 지수 상품이므로 별도 한도로 리스크실 협의).

## 6. 검증용 예제

**조건**: E_s = 12,000,000원(현재 전액 현금), 월말 T
| 자산 | RET63 | RET126 | RET252 | M | C_T | SMA200 | 판정 |
|---|---|---|---|---|---|---|---|
| A (KODEX 200) | +4.0% | +9.0% | −2.0% | +3.67% | 41,000 | 39,500 | risk_on |
| B (코스닥150) | −3.0% | −6.0% | +1.0% | −2.67% | 12,500 | 13,100 | off |
| SAFE | +0.8% | +1.5% | +3.1% | +1.80% | — | — | safe_on |

→ w_A = 0.5, w_B = 0, w_SAFE = 0.5, w_CASH = 0
→ A 매수 수량 = floor(0.5 × 12,000,000 × 0.995 / 41,000 = 145.6) = **145주**

## 9. 모의투자(P3) 통과 기준 — D-002 이행
공통 기준은 `EVALUATION.md` §3.3을 따르고, S03에만 해당하는 사항은 다음과 같습니다.

| 항목 | 기준 |
|---|---|
| 기간 | 8주 이상, **월말 신호일 ≥ 2회**를 포함할 때까지 (최대 12주) |
| 중점 확인 | ① 월말 신호일 판정(마지막 거래일, 휴장일 반영) ② 리밸런싱 밴드 5%p 적용과 비중 0 전환 시 전량 매도 ③ 매도 후 매수 순서와 현금 버퍼 0.5% ④ ETF 매도 시 거래세가 0으로 처리되는지(회계팀 대사) |
| 신호 일치율 | 100% (신호일이 적으므로 1건이라도 틀리면 불합격) |
| 참고 | 8주 동안 리밸런싱 매매가 한 번도 없을 수 있습니다. 그 경우 **과거 월말 날짜로 신호 엔진을 재생하는 리플레이 시험**(최근 24개월)으로 대신 검증합니다 |

## 10. D-005 모드 (10만원 모의·소액 단계) 관련 — COMMON_SPEC §15 우선
- 10만원 단계에서는 주문 목표가 약 2만원이라, 이 전략의 주요 대상(국내 대형주, 지수 ETF 등 1주 2만원 초과)을 대부분 살 수 없습니다. 또 보유기간이 D-003의 우선 검증 범위(1~5거래일)보다 깁니다. 그래서 **이 전략은 자본 T1(100만원) 이상 단계에서 모의투자를 시작**하는 것으로 미룹니다. P2 백테스트는 일정대로 진행합니다.
- 그 단계에서도 사이징은 COMMON_SPEC §15.1을 우선 적용하며, 자본 단계가 바뀔 때 다시 정합니다(`CAPITAL_SCALING.md`).
