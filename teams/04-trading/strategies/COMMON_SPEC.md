# 전략 공통 규격서 (COMMON_SPEC) v0.1

> 대상 독자: ③ 프로그램 생성팀 (백테스트 엔진, 신호 엔진, 주문 모듈 담당)
> 모든 전략 명세서(S01~S03)는 이 문서의 정의를 **그대로 상속**합니다. 전략 문서와 이 문서가 충돌하면 전략 문서가 우선합니다.
> 이 문서에서 "가정값"으로 표시된 수치는 타 팀 확정 전 임시값이며, 반드시 설정 파일의 파라미터로 구현합니다(하드코딩 금지).

## 1. 용어

| 용어 | 정의 |
|---|---|
| T | 신호 산출일 (해당 거래일 장 마감 후 데이터 확정) |
| T+1 | T 다음 **거래일** (주말·휴장일 제외, KRX 영업일 캘린더 기준) |
| 슬리브(sleeve) | 전략별 가상 하위계좌. 현금·포지션·손익을 전략별로 따로 장부 처리 |
| 총자산 `E_total` | 실계좌(또는 백테스트 계좌)의 현금 + 보유주식 평가액 (T 종가 기준) |
| 슬리브 자산 `E_s` | 해당 슬리브 현금 + 해당 슬리브 보유분 평가액 (T 종가 기준) |
| R | 1주당 초기 위험 = 진입가 − 초기 손절가 (원). 거래 성과를 R 배수로 표기 |
| 보유일수 | 진입 체결일을 0으로 하여 센 **거래일** 수 |
| 수정주가 | 액면분할·병합·무상증자·유상증자 권리락 등을 반영해 과거를 소급 조정한 가격 (배당 미반영, price-adjusted) |
| 원주가(raw) | 해당 일자에 실제 거래된 가격 |

## 2. 데이터 요구사항 (② 자료팀에 요청됨)

| 데이터 | 필드 | 주기 | 기간 | 비고 |
|---|---|---|---|---|
| 개별주 일봉 | date, ticker, open, high, low, close, volume, 거래대금(value, 원) | 일 | 2010-01-01 ~ 현재 | **원주가와 수정주가 모두**, 수정계수(adj_factor) 포함 |
| 지수 일봉 | KOSPI200, KOSDAQ150 지수 OHLC / KOSPI200 TR 지수 | 일 | 동일 | 국면 필터, 벤치마크용 |
| ETF 일봉 | S03 대상 ETF OHLCV, 분배금 내역 | 일 | 상장일 ~ 현재 | 분배금은 TR 계산에 사용 |
| 지수 구성종목 | KOSPI200/KOSDAQ150 **시점별(Point-in-Time)** 편입·편출 이력 | 정기변경 시 | 2010 ~ | **생존편향 방지 필수** |
| 종목 상태 플래그 | 관리종목, 투자주의환기, 투자경고, 투자위험, 단기과열, 거래정지, 정리매매, 상장폐지일 | 일 | 2010 ~ | 시점별 |
| 종목 속성 | 시장구분(KOSPI/KOSDAQ), 상장일, 주식 종류(보통/우선), SPAC 여부, 업종(섹터) | 이벤트 | | 섹터 분류 체계는 자료팀이 결정(GICS/WICS/KRX 업종) |
| 휴장일 캘린더 | KRX 영업일 | 연 | 2010 ~ 2027 | |

**데이터 처리 원칙**
1. 신호 계산(지표, 수익률, 돌파 판정)에는 **수정주가**를 사용합니다.
2. 거래대금 필터, 최소가격 필터, 호가단위, 주문가격, 상·하한가 판정에는 **원주가**를 사용합니다.
3. 백테스트는 T일 시점에 알 수 있었던 정보만 씁니다(look-ahead 금지). 지수 구성종목과 상태 플래그는 T일 기준 값을 씁니다.
4. 결측: 해당 종목의 직전 250거래일 중 결측(거래정지 포함)이 5일을 넘으면 T일 유니버스에서 제외합니다.

## 4. 시장 국면 필터 (Regime)

```
regime_on(market, T) = index_close(market, T) > SMA(index_close(market), 200)_T
  market = KOSPI  → 지수: KOSPI200
  market = KOSDAQ → 지수: KOSDAQ150
```
- 종목의 시장 구분은 T일 기준 상장시장을 따릅니다.
- 200일 이동평균 기간은 **고정값**이며 최적화 대상이 아닙니다(과최적화 방지).

## 5. 지표 정의 (모두 수정주가, T일 종가 확정 후 계산)

| 지표 | 정의 | 주의 |
|---|---|---|
| `SMA(x,n)_T` | x_{T−n+1}~x_T 의 단순평균 | 값이 n개 미만이면 NaN → 해당 신호는 False |
| `TR_t` | max(H_t − L_t, \|H_t − C_{t−1}\|, \|L_t − C_{t−1}\|) | 첫날은 H−L |
| `ATR(n)_T` | **TR의 단순평균** SMA(TR, n)_T | Wilder 평활이 아닙니다(재현성을 위해 SMA 사용) |
| `ATRpct(n)_T` | ATR(n)_T / C_T | |
| `RSI(n)_T` | Wilder RSI. 첫 평균 = 최초 n개 변화량의 단순평균, 이후 avg_t = (avg_{t−1}·(n−1) + x_t)/n. RSI = 100 − 100/(1+avg_gain/avg_loss) | avg_loss=0 이면 100, avg_gain=avg_loss=0 이면 50. 계산 시작점은 종목 데이터 첫날, 워밍업은 최소 50봉 |
| `HH(x,n)_T` | max(x_{T−n}~x_{T−1}) — **T일 제외** 직전 n일 최고값 | 돌파 판정용 |
| `LL(x,n)_T` | min(x_{T−n}~x_{T−1}) — T일 제외 | |
| `RET(n)_T` | C_T / C_{T−n} − 1 | |
| `ADV20_T` | 원주가 거래대금 T−19~T 평균 (원) | 유니버스·유동성 상한용 |
| `ADV20prev_T` | 원주가 거래대금 T−20~T−1 평균 (원) | 거래대금 급증 판정용 (T일 제외) |

## 7. 주문·체결 규칙

### 7.1 주문 유형

| 코드 | 실전 집행 | 백테스트 체결 가정 |
|---|---|---|
| `MOO` (시가 시장가) | T+1 장전 동시호가에 **시장가** 주문 | T+1 시가 × (1 ± slip). 매수는 +, 매도는 − |
| `LOO` (시가 지정가, 장 시작 후 취소) | T+1 장전 동시호가에 지정가 L, 09:05 미체결분 취소 | 시가 ≤ L 이면 시가 × (1 + slip)로 체결. 아니면 미체결 |
| `LDAY` (당일 유지 지정가) | T+1 장전 동시호가에 지정가 L, 15:15까지 유지 후 취소 | 시가 ≤ L 이면 시가로 체결. 아니면 저가 < L(**엄격 부등호**, 대기열 보수 가정)일 때 L로 체결. 둘 다 아니면 미체결. 지정가 체결에는 slip 미적용 |

### 7.2 호가단위 (원주가, KRX 2023년 개편 기준, 코스피·코스닥 동일) — 자료팀 검증 요청됨

| 가격 구간 | 호가단위 |
|---|---|
| < 2,000 | 1 |
| 2,000 ~ < 5,000 | 5 |
| 5,000 ~ < 20,000 | 10 |
| 20,000 ~ < 50,000 | 50 |
| 50,000 ~ < 200,000 | 100 |
| 200,000 ~ < 500,000 | 500 |
| ≥ 500,000 | 1,000 |
| ETF/ETN | < 2,000원 1원, 그 외 5원 |

- 매수 지정가: `tick_floor(p)` (호가단위로 내림). 매도 지정가: `tick_ceil(p)` (올림).
- 백테스트는 호가 반올림을 생략할 수 있습니다(설정 `backtest.apply_tick=false`, 기본값). 실전·모의에서는 필수입니다.

### 7.3 미체결·예외 처리

| 상황 | 실전 | 백테스트 |
|---|---|---|
| 진입 주문 미체결 | 취소. 다음 날 재진입은 그날 신호가 다시 나올 때만 | 미체결 |
| 진입 부분체결 | 체결분만 보유, 잔량 취소. 손절가는 동일 | 부분체결 없음(유동성 상한 §7.4로 정당화) |
| 청산 주문 미체결(시장가인데 미체결) | 09:05에 정규장 시장가로 재주문. 체결될 때까지 5분 간격으로 재시도하고, 3회 실패하면 알림 | 해당 없음 |
| 시가가 하한가(전일 원주가 종가 × 0.70의 호가 올림가 이하) | 청산 시장가 유지 | **그날 청산 미체결**로 가정하고 다음 거래일 시가에 재시도 (보수 가정) |
| 시가가 상한가 | 진입은 LOO/LDAY 한도가 걸려 자연히 미체결 | 동일 |
| 보유 종목 거래정지 | 청산 주문은 재개일 첫 장전 동시호가로 이연 | 정지 기간 평가가는 마지막 종가. 재개일 시가로 청산 |

### 7.4 유동성 상한
- 1건 주문금액 ≤ `ADV20_T × 1%` (파라미터 `exec.max_adv_participation = 0.01`). 이를 넘는 수량은 깎습니다.

### 7.5 동시 체결 시 현금 사용
- 국내 주식은 매도 체결 즉시 매도대금을 재매수에 쓸 수 있습니다(T+2 결제와 무관, 프로그램팀이 API에서 확인).
- 주문계획 수립 시 진입에 쓸 수 있는 현금은 다음과 같습니다.
  `cash_avail_s = 슬리브 현금 + Σ(해당 슬리브 청산 예정 수량 × C_T × 0.97)`
- 실제 매수가능금액이 부족해 주문이 거절되면 **순위가 낮은 진입부터** 포기합니다.

## 10. 포지션 사이징 공통식

개별주 전략의 매수 수량은 아래 상한들 중 **가장 작은 값**입니다.

```
Q_risk   = floor( E_total × risk_per_trade / (L_ref − stop_ref) )      # 1건 위험 한도
Q_weight = floor( E_total × max_weight_per_stock / L_ref )              # 1종목 비중 한도 (전 슬리브 합산)
Q_slot   = floor( E_s / max_positions_s / L_ref )                       # 슬롯 균등 한도 (전략별로 사용 여부 지정)
Q_cash   = floor( cash_avail_s / (L_ref × (1 + commission_rate)) )      # 현금 한도
Q_liq    = floor( ADV20_T × max_adv_participation / L_ref )             # 유동성 한도
Q = min(위 항목들)
if Q × L_ref < exec.min_order_krw (기본 200,000원): 주문하지 않음
```
- `L_ref` = 매수 지정가 (시장가 주문이면 C_T × 1.03)
- `stop_ref` = L_ref 기준으로 계산한 초기 손절가 (전략 명세서 정의)
- 체결 후 실제 초기 손절가는 **실제 체결가 기준으로 다시 계산**합니다. 수량은 그대로 둡니다.
- 한 종목은 한 슬리브만 보유할 수 있습니다. 다른 슬리브가 보유 중인 종목에는 진입 신호를 무시합니다.

## 11. 신호 처리 순서 (매 T일, 결정론적이어야 함)

```
for T in trading_days:
  1. 데이터 로드 및 QC (실패하면 이번 T에는 신규 진입 금지 플래그)
  2. 강제 청산(§8) 판정
  3. 전략별 청산 신호 판정 (전략 문서의 판정 순서대로, 첫 번째로 맞는 사유 하나만 기록)
  4. 보유 포지션의 손절가 갱신 (트레일링)
  5. 슬리브 우선순위 S03 → S01 → S02 순으로 진입 후보 산출 → 전략별 순위 정렬 → 사이징
  6. 리스크 관문 (RISK_ALIGNMENT 한도) 통과 주문만 주문계획에 기록
  7. T+1 체결 시뮬레이션 (백테스트) / 실전 주문 제출
  8. 체결 반영, 장부 갱신, 로그 기록
```
- 같은 조건이면 결과가 언제나 같아야 합니다. 동점은 **종목코드 오름차순**으로 깹니다.
