# S02 — 상승추세 눌림목 반등 (MR-PB) 전략 명세서 v0.1

| 항목 | 내용 |
|---|---|
| 상태 | `SPEC` (명세 완료 → P2 백테스트 대기) |
| 버전 | v0.1 / 2026-11-23 |
| 상속 | `COMMON_SPEC.md` 전체 |
| 슬리브 비중(제안) | 총자산의 30% |
| 유형 | 단기 평균회귀, 롱온리, 승률형 (예상 승률 60~70%, 손익비 1 미만) |
| 예상 보유기간 | 2~7거래일 |

## 1. 가설
국내 시장은 단기(1~5일) **수익률 반전 효과**가 강한 편입니다. 개인 투자자의 투매, 반대매매, 프로그램 매도로 생긴 과매도가 며칠 안에 되돌아가는 일이 잦습니다. 단, 아무 종목이나 떨어졌다고 사면 "떨어지는 칼날"을 잡게 됩니다. 그래서 **장기 상승추세(200일선 위)**인 종목만, **시장 국면이 ON**일 때만, **악재성 폭락(하루 −10% 이하)은 제외**하고 삽니다.

**실패하는 국면**: 하락 전환 초기(200일선 위에 있던 종목들이 줄줄이 무너짐), 개별 악재(실적 쇼크, 회계 이슈)가 며칠에 걸쳐 반영될 때.

## 3. 진입 규칙 (T일 종가 후)

| # | 조건 | 수식 |
|---|---|---|
| E1 | 유니버스 | i ∈ U_T |
| E2 | 시장 국면 ON | regime_on(market_i, T) |
| E3 | 장기 상승추세 | C_T > SMA(C,200)_T |
| E4 | 단기 과매도 | RSI(2)_T < rsi_entry |
| E5 | 악재성 폭락 제외 | RET(1)_T > −0.10 |
| E6 | 미보유 | 어떤 슬리브도 i를 보유하지 않음 |
| E7 | 당일 재진입 금지 | 직전 거래일에 S02에서 i를 청산하지 않았음 |

**순위**: RSI(2)_T 오름차순 → 동점이면 ADV20_T 내림차순 → 종목코드 오름차순.
**선정**: `min(max_new_per_day, max_positions − 현재 보유 수)`개.

## 4. 진입 주문

```
L        = tick_floor( C_T(raw) × 1.00 )                  # 주문유형 LDAY (15:15까지 유지)
stop_ref = L × (1 − stop_pct)
Q        = min(Q_risk, Q_weight, Q_slot, Q_cash, Q_liq)     # COMMON_SPEC §10
```
- 백테스트 체결: Open_{T+1} ≤ L 이면 Open_{T+1}(slip 없음), 그렇지 않고 Low_{T+1} < L 이면 L, 둘 다 아니면 미체결
- init_stop = fill × (1 − stop_pct), R = fill − init_stop
- 트레일링 없음 (stop 고정)

## 5. 청산 규칙 (T일 판정 → T+1 `MOO`)

| 순서 | 코드 | 조건 |
|---|---|---|
| 0 | X_ADMIN/X_KILL | COMMON_SPEC §8 |
| 1 | X_STOP | C_T ≤ init_stop |
| 2 | X_TP | C_T > SMA(C,5)_T |
| 3 | X_TIME | 보유일수 ≥ time_stop_days |

- 진입 당일(보유일수 0)의 종가도 청산 판정 대상입니다. 진입일 종가가 이미 5일선 위면 다음 날 시가에 청산합니다.
- 국면이 꺼져도 강제 청산하지 않습니다(보유가 짧아서). 신규 진입만 막힙니다.

## 6. 검증용 예제

**조건**: E_total = 30,000,000원, S02 슬리브 E_s = 9,000,000원(가용현금 충분), KOSDAQ 종목, C_T = 18,450원, ADV20_T = 50억원, stop_pct = 0.08

| 단계 | 계산 | 결과 |
|---|---|---|
| 지정가 | tick_floor(18,450) — 호가단위 10 | **L = 18,450** |
| stop_ref | 18,450 × 0.92 | 16,974 (거리 1,476) |
| Q_risk | floor(150,000 / 1,476 = 101.6) | 101 |
| Q_weight | floor(3,000,000 / 18,450 = 162.6) | 162 |
| Q_slot | floor(9,000,000 / 6 / 18,450 = 81.3) | 81 |
| Q_liq | floor(50,000,000 / 18,450 = 2,710.0) | 2,710 |
| **Q** | min | **81주** (1,494,450원) |
| T+1: 시가 18,600 > L, 저가 18,300 < L | 지정가 체결 | **fill = 18,450**, init_stop = 16,974 |
| T+3 종가 19,050 > SMA5 18,900 | X_TP | T+4 시가 청산 |

## 7. 백테스트 변형
- V1: X_TP·X_TIME 청산을 **당일 종가 단일가**로 집행 (평균회귀 전략은 하루 늦은 청산에 민감하므로 반드시 비교)
- V2: 손절 없음 (stop_pct = ∞) — 손절의 비용과 효과 측정용. 채택 후보는 아님
- V3: E3를 C_T > SMA(C,100)_T 로 완화

## 8. 벤치마크
KOSPI200 TR. 그리고 같은 유니버스에서 국면 ON·200일선 위 종목 중 **무작위 진입 + 같은 청산 규칙**.

## 9. 모의투자(P3) 통과 기준 — D-002 이행
공통 기준은 `EVALUATION.md` §3.3을 따르고, S02에만 해당하는 사항은 다음과 같습니다.

| 항목 | 기준 |
|---|---|
| 기간 | 8주 이상, **체결 거래 ≥ 20건**을 채울 때까지 (최대 12주) |
| 중점 확인 | ① LDAY 지정가 주문이 15:15에 잔량 취소되는지 ② 지정가 체결 판정(저가 < L 엄격 부등호)과 실제 체결 비교 — 대기열 때문에 실제 체결률이 백테스트보다 낮은지 측정 ③ 진입 당일 종가 청산 판정이 작동하는지 |
| 체결 여부 일치율 | ≥ 95% (LDAY). **실제 체결률이 백테스트 가정보다 10%p 넘게 낮으면** 체결 모델을 보수적으로 바꾸고 P2 재평가 |
| 참고 지표 | 승률은 표본 20건 기준 신뢰구간이 넓으므로 판정에 쓰지 않음. 단, 승률이 40% 미만이면 3자 검토 안건으로 올림 |
