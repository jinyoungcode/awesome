# 전략 평가 기준 및 과최적화 방지 규칙 v0.1 (1차 과업 ③·④)

> 이 문서는 백테스트 엔진의 **리포트 출력 요건**이자 전략 **채택·폐기 기준**입니다.
> 합격 기준값은 대표가 목표 수익률과 허용 MDD를 정하면(Q-T02) 그에 맞춰 확정합니다. 아래는 중립형 기준입니다.

---

## 1. 평가 지표 정의 (프로그램팀 구현 사양)

모든 지표는 **비용·세금 차감 후(net)** 값을 기본으로 냅니다. 비용 차감 전(gross) 값은 비교용으로 함께 출력합니다.
입력: `equity_daily.csv`의 일별 자산 `E_t` (t = 0..N), 일수익률 `r_t = E_t / E_{t−1} − 1`, `trades.csv`

| 지표 | 정의 | 비고 |
|---|---|---|
| CAGR | (E_N / E_0)^(252 / N) − 1 | N = 거래일 수 |
| 연변동성 | std(r_t, ddof=1) × √252 | |
| 샤프 | mean(r_t − rf_d) / std(r_t, ddof=1) × √252 | rf_d = (1+rf)^(1/252) − 1. MVP는 rf = 0으로 냅니다. rf = 연 3.0%(가정)도 함께 출력 |
| 소르티노 | mean(r_t − rf_d) / sqrt(mean(min(r_t − rf_d, 0)²)) × √252 | 분모는 전체 일수 기준 하방편차 |
| MDD | min_t( E_t / max_{s≤t} E_s − 1 ) | 음수(%)로 표기 |
| 최장 낙폭 기간 | 고점 갱신 사이의 최대 거래일 수 | |
| 칼마 | CAGR / \|MDD\| | |
| 거래 수 | 청산 완료 거래 건수 | |
| 승률 | net_pnl > 0인 거래 수 / 거래 수 | |
| 손익비(Payoff) | 평균 이익 거래 net_pnl / \|평균 손실 거래 net_pnl\| | |
| Profit Factor | Σ 이익 거래 net_pnl / \|Σ 손실 거래 net_pnl\| | |
| 기대값(R) | mean(r_multiple) | 거래당 기대 R |
| 평균 보유일 | mean(holding_days) | |
| 노출도 | 보유 포지션이 있는 날의 평균 (positions_value / equity) | |
| 연 회전율 | (Σ 매도 체결금액 / 평균 equity) / 연수 | 편도 |
| 비용 잠식 | CAGR_gross − CAGR_net | 연 %p |
| 최대 연속 손실 | 연속된 손실 거래의 최대 건수 | |
| 상관·베타 | 일수익률 기준 KOSPI200 TR 대비 상관계수, 베타 | |
| 연도별·월별 수익률 표 | 달력 연·월별 수익률 | |
| 이익 집중도 | 상위 10개 거래의 net_pnl 합 / 전체 net_pnl | |
| 연도 집중도 | 최대 이익 연도의 net_pnl / 전체 net_pnl | |

## 2. 데이터 구간 분할 (고정, 사전 공표)

| 구간 | 기간 | 용도 | 사용 규칙 |
|---|---|---|---|
| 워밍업 | 2010-01 ~ 2011-12 | 지표 계산용(SMA200, RET252 등) | 성과 집계 제외 |
| **IS (학습)** | 2012-01-02 ~ 2019-12-30 (8년) | 파라미터 탐색 | 자유롭게 사용 |
| **OOS (검증)** | 2020-01-02 ~ 2023-12-28 (4년) | IS에서 고른 파라미터 검증 | 파라미터를 바꾸지 않고 **한 번에** 평가 |
| **Holdout (봉인)** | 2024-01-02 ~ 2026-10-30 (약 2.8년) | 최종 확인 | **전략당 1회만** 엽니다. 연 뒤에 규칙을 바꾸면 그 버전은 Holdout을 잃습니다. 이후 검증은 모의투자로 대신합니다 |

- OOS에는 2020년 코로나 급락·급반등, 2021년 고점, 2022년 약세장이 들어 있어 스트레스 구간으로 적합합니다.
- 자료팀 데이터가 2010년 이전까지 확보되면 IS를 앞으로 늘릴 수 있습니다. 그 경우에도 OOS·Holdout 경계는 바꾸지 않습니다.

**워크포워드(WF)**: IS+OOS 구간(2012~2023)에서 학습 4년, 검증 1년, 1년씩 이동하며 8개 창(검증 연도 2016~2023)을 돌립니다. 각 창에서 학습 구간 샤프가 최대인 조합을 골라 다음 1년에 적용하고, 검증 구간들을 이어 붙인 수익 곡선을 따로 보고합니다.

#### (4) 주의 사항
- 증권사 모의투자는 체결이 실전보다 **유리하게** 처리되는 경우가 많습니다(호가 잔량 무시 등). 그래서 P3·P4를 통과해도 P4 소액 실전 첫 4주에 같은 기준으로 **실전 슬리피지를 다시 측정**하고, 가정값의 2배를 넘으면 증액을 보류합니다.
- 전략별 통과 판정은 독립적입니다. 통과한 전략만 P4로 넘어갈 수 있습니다(예: S03만 먼저 실전 투입 가능). 단, 시스템 공통 항목(P7~P11)은 계좌 단위로 판정합니다.

### 3.4 무작위 진입 몬테카를로 (우연 배제 검정)
- 진입 날짜별로 실제 전략이 산 종목 수만큼 **같은 날의 적격 후보군(전략별 정의)**에서 무작위로 고릅니다. 청산·사이징 규칙은 그대로 씁니다. 이를 1,000회 반복합니다(seed 고정·기록).
- 실제 전략의 IS+OOS 샤프가 무작위 분포의 95% 분위수를 넘어야 합니다.

## 4. 과최적화 방지 규칙 (강제 사항)

1. **튜닝 파라미터는 전략당 최대 3개**, 각 파라미터 그리드는 최대 5개 값, 조합 총합은 최대 100개입니다. 그 밖의 값은 명세서에 "고정"으로 적고 바꾸지 않습니다.
2. **시행 기록**: 모든 백테스트 실행(파라미터, 데이터 버전, 코드 커밋, 결과)은 `teams/04-trading/research/trial_log.csv`에 자동 기록합니다. 보고서에는 "총 시행 횟수"를 반드시 적습니다. 결과가 나쁜 시행을 지우는 것은 금지합니다.
3. **선택 규칙**: 최고점이 아니라 **고원 중심**을 고릅니다. 각 조합의 IS 샤프를, 그 조합과 그리드에서 한 칸씩 인접한 조합들의 IS 샤프와 평균합니다(이웃 평균). 이웃 평균이 가장 높은 조합을 채택합니다.
4. **고원 검사**: 채택 조합에서 각 파라미터를 한 칸씩 움직인 모든 인접 조합의 샤프가 채택 조합의 70% 이상이어야 합니다(G11).
5. **구간 봉인**: OOS 결과를 본 뒤 규칙이나 필터를 추가·변경하면 **새 버전(v0.2 등)**으로 등록하고, 시행 기록에 "OOS 노출 후 변경"이라고 표시합니다. OOS를 보고 바꾼 버전은 Holdout 통과가 필수입니다. Holdout을 쓴 뒤 다시 바꾸면 모의투자 8주로만 검증합니다.
6. **사후 필터 금지**: 손실 거래를 보고 "이 종목·이 시기를 빼자"는 식의 예외 규칙은 금지합니다. 필터는 경제적 근거를 명세서 '가설'란에 먼저 적어야 추가할 수 있습니다.
7. **데이터 무결성**: 시점 기준 구성종목, 상장폐지 종목 포함, 수정주가 검증을 통과한 데이터 버전으로만 평가합니다. 데이터 버전 해시를 리포트에 적습니다.
8. **현실성 검사**: 결과가 "샤프 > 2.0" 또는 "MDD > −5%이면서 CAGR > 20%"이면 자동으로 **버그 의심** 플래그를 붙이고, 원인을 찾을 때까지 채택하지 않습니다.
