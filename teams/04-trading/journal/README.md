# 운용 일지 (journal)

모의투자(P3)부터 매 거래일 1개 파일을 씁니다: `journal/YYYY/YYYY-MM-DD.md`. 기본 내용은 시스템이 자동으로 채우고, 운용 일지 담당이 코멘트를 붙입니다.

## 일지 양식

```markdown
# YYYY-MM-DD 운용 일지 (모의/실전)

## 1. 계좌 요약
| 총자산 | 일손익(원/%) | 누적수익률 | 계좌 고점 대비 낙폭 | 킬스위치 단계 |
|---|---|---|---|---|

## 2. 슬리브별
| 전략 | 자산 | 일손익 | 보유 수 | 노출도 |
|---|---|---|---|---|

## 3. 체결 내역
| 전략 | 종목 | 매수/매도 | 주문유형 | 수량 | 계획가 | 체결가 | 슬리피지(%) | 사유코드 |
|---|---|---|---|---|---|---|---|---|

## 4. 계획 대비 괴리
- 미체결 진입: (종목, 사유)
- 백테스트 재실행 신호와 불일치: 0건 / (있으면 상세)
- 리스크 관문 탈락 주문: (사유코드)

## 5. 규칙 외 행동 (수동 개입, 장애 등) — 있으면 반드시 기록
## 6. 코멘트 (시장 상황, 관찰 사항 — 규칙 변경 제안은 여기가 아니라 전략 버전업으로)
```

## 주간 괴리 분석 (매주 금요일, `journal/YYYY/WW-review.md`)
- 실측 슬리피지 평균과 가정값 비교
- 같은 기간 백테스트 재실행 수익률과 실제 수익률의 괴리
- 전략별 거래 수, 승률, 기대값(R)과 백테스트 분포 비교

## 모의투자 5거래일(11/26·11/27·11/30·12/1·12/2, D-043) 일지 추가 항목 (D-024 점검표 연동)

매일 장 마감 후(체결 동기화·장부 대사가 끝난 뒤) `journal/2026/2026-MM-DD.md`에 위 기본 양식과 함께 아래를 적습니다. 시스템이 자동으로 채우는 칸은 (자동), 운용 일지 담당이 판단해 적는 칸은 (판단)으로 표시합니다.

```markdown
## 7. 3일 모의 점검 (D-024)
| 항목 | 기준 | 오늘 결과 | 누적 |
|---|---|---|---|
| C1 장부·잔고 대사 | 100% | (자동) 일치/불일치 n건 | |
| C2 신호 일치 (백테스트 재실행 대비) | 100% | (자동) 일치/불일치 n건 + 불일치 종목 | |
| C3 오주문·중복 | 0건 | (자동) | |
| C4 킬스위치 훈련 | 1회 | (판단) 실시 여부·발동→해제 시각·매수 차단/매도 허용 확인(D-026) | |
| C5 재시작 복구 | 1회 | (판단) 실시 여부·결과 | |
| C6 모의 주문 수 | ≥ 5건 | (자동) 오늘 n건 (전략 / T_TECH 구분) | |

## 8. S02 운용 내역
- 오늘 주문계획: 진입 n건 / 청산 n건 (사유코드별), 사이징 불가로 건너뛴 후보 n건과 사유
- 체결: LDAY 진입 체결 n/n, MOO(또는 시장성 지정가) 청산 체결 n/n
- 체결가 괴리: 진입은 지정가 대비, 청산은 당일 시가 대비 슬리피지(%) (자동)
- 1주 예외: UNDER n건, OVER n건 (보유 중 OVER 개수)
- 리스크 관문 거절: 사유코드별 건수 (자동)
- 국면 필터: KOSPI200 / KOSDAQ150 ON·OFF (자동)
- 보유 현황: 종목, 수량, 진입가, 손절가, 보유일수, 예외 구분 (자동)

## 9. 계좌·목표
- 모의 운용 금액(D-044), 평가자산, 실현 순손익, 일간 수익률, 일간 +5% 도달 여부(D-004, 기록용) (자동)
- **수수료 두 기준 손익**: 기본 0.15%(D-045, 현재 요율 0.147% + 제비용) 기준 실현 손익과, 참고 시나리오 0.018% 기준 실현 손익을 함께 기록. 체결 내역에서 확인한 **실제 적용 수수료율**도 적음 (`COST_IMPACT_BRANCH_RATE.md`)
- 일중 손실 한도(−5%) 근접 여부 (자동)

## 10. 그날만 하는 항목
- 1일차(11/26, 기술 점검만): 접속, 1주 주문·취소, 킬스위치, 재시작 복구, 장부 대사 결과. S02 항목(8번)은 "주문 없음"으로 기록
- 2일차(11/27): S02 첫 주문 결과
- 3~5일차(11/30·12/1·12/2): 장전 시장가 매도(MOO) 확인 결과(청산 대상이 처음 생긴 날, §6.1-1)
- 4일차(12/1): D-027 발동 판정 결과와 근거 수치 (§6.1)
- 5일차(12/2): 점검용 주문 T1~T5 실행 결과(발동 시), 모의 종합 C1~C6 판정과 연장 여부
```
