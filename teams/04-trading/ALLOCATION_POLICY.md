# 전략 간 자금 배분 규칙 (Q-T04 대표 결정 이행) v0.1

> 대표 결정 (2026-11-23): **"상황에 맞게 전적으로 알아서 배분해서 투자"**
> 매매팀 원칙: "알아서"는 사람이 그때그때 감으로 정한다는 뜻이 아닙니다. 매매팀이 **미리 정한 규칙으로 자동 배분**하겠습니다. 감으로 배분하면 백테스트로 검증할 수 없고 실패 원인도 찾을 수 없습니다.
> 대상 독자: ③ 프로그램팀(배분 엔진 구현), ① 리스크관리실(한도 확인)

## 1. 배분 대상 (슬리브)

| 슬리브 | 전략 | 비고 |
|---|---|---|
| DK | 국내 데이트레이딩 (D01, D02 …) | 주력 |
| DU | 미국 데이트레이딩 (D03 …) | **국내 데이트레이딩과 동시에 편입** (대표 결정 Q-T12 ①). 단, `DAYTRADING_REVIEW.md` §8 안전장치가 구현되어야 가동 |
| SW | 스윙 (S01, S02; 미국 스윙 추가 가능) | |
| CO | ETF 배분 (S03) | 하락장 방어용. 필요할 때만 편입 |
| CASH | 미배정 현금 | |

- 상태가 `LIVE`인 전략만 자금을 받습니다(`EVALUATION.md` §5).

## 2. 월간 배분 산식 (매월 첫 거래일 08:00, 전월 말 데이터 기준)

```
for each LIVE sleeve s:
    vol_s   = 최근 60거래일 슬리브 일수익률 표준편차 × √252
              (실전 이력이 60일 미만이면 백테스트 OOS 연변동성 사용)
    raw_s   = 1 / max(vol_s, 0.05)                         # ① 위험 균등 (변동성 역가중)
    raw_s  *= dd_haircut_s                                  # ② 성과 감액
    raw_s  *= ramp_s                                        # ③ 신규 전략 단계 편입
    raw_s  *= regime_mult_s                                 # ④ 시장 국면

w_s = raw_s / Σ raw                                         # 정규화
w_s = clip(w_s, 0.10, 0.50)  → 다시 정규화                  # ⑤ 슬리브당 10~50%
|w_s − w_s(전월)| ≤ 0.15 로 제한                             # ⑥ 월간 변경폭 ±15%p
```

| 요소 | 규칙 |
|---|---|
| ② `dd_haircut_s` | 슬리브 고점 대비 낙폭이 전략 정지 한도(K3)의 절반을 넘으면 0.5, 아니면 1.0 |
| ③ `ramp_s` | LIVE 편입 1개월차 0.25, 2개월차 0.5, 3개월차 0.75, 4개월차부터 1.0. 국내 데이트레이딩(DK)은 리스크실 조건에 따라 반드시 0.25부터 시작 (`DAYTRADING_REVIEW.md` §9) |
| ④ `regime_mult_s` | KOSPI200 < SMA200(국면 OFF)이면 SW(롱 스윙) 0.5, CO 1.5. 데이트레이딩은 1.0 (당일 청산이라 국면 영향이 작음) |
| CO 편입 조건 | 국면 OFF일 때만 CO에 배분. 국면 ON이면 CO = 0 |
| 데이트레이딩 실제 사용액 | DK·DU에 배정된 금액 중 장중 동시 노출은 최대 100% (레버리지 없음) |

## 3. 집행

- 배분 변경은 **슬리브 간 가상 현금 이동**으로만 합니다. 배분을 맞추려고 강제로 매도하지 않습니다. 현금이 부족한 슬리브는 포지션이 청산되는 대로 순차적으로 맞춥니다.
- 국내↔미국 이동은 환전이 필요합니다. 환전은 월 1회, 이동액이 총자산의 5%를 넘을 때만 합니다(환전 비용 절감).
- 배분 결과는 매월 `teams/04-trading/journal/YYYY/allocation_YYYYMM.md`에 자동 기록하고 대표에게 요약 알림을 보냅니다.

## 4. 예외 조정 (헤드 트레이더 권한)

- 시스템 장애, 시장 폐쇄 같은 비상시에만 산식 결과를 수동으로 바꿀 수 있습니다.
- 바꿀 때는 사유를 일지에 기록하고 총괄운영팀에 통보합니다. 리스크 한도(RISK_ALIGNMENT)를 넘는 조정은 할 수 없습니다.

## 5. 검증

- P2에서 이 배분 규칙을 적용한 결합 백테스트와 고정 배분(동일 비중)을 비교합니다.
- 배분 규칙이 고정 배분보다 샤프가 낮거나 MDD가 깊으면 고정 배분으로 대체합니다(규칙이 오히려 성과를 깎는 경우가 있기 때문입니다).
- 튜닝 파라미터는 없습니다. 위 숫자는 모두 고정값입니다(과최적화 방지).
