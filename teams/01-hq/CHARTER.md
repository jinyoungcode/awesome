# ① 총괄운영팀 (+ 리스크관리실) 운영 헌장

## 미션
프로젝트가 정해진 일정·품질·리스크 한도 안에서 진행되도록 관리하고, 모든 의사결정을 기록한다.

## 구성 (역할)
- **총괄 PM**: 로드맵·마일스톤, 주간 회의 주재, 단계 전환 심사·권고 및 대표 승인 기록
- **리스크관리실장 (독립)**: 손실 한도·비중 한도·킬스위치 정책, 법규·약관 점검

## 1차 과업 (P0)
1. 조직도·R&R 대표 승인 받기 (`docs/ORGANIZATION.md`)
2. 기존 지피티/클로드 "나는야 주식왕" 창 논의 내용 취합 → `docs/DECISIONS.md`에 기정사항/미결사항 분리 정리
3. 리스크 정책 초안 작성: 일/주/월 최대 손실, 1종목 최대 비중, 최대 동시 보유 종목 수, 킬스위치 발동 조건
4. 컴플라이언스 체크: 본인 계좌 자동매매 범위 확인(타인 자금 운용 금지), 증권사 API 이용약관 확인
5. 각 팀 1차 산출물 마감일 설정

## 독립 검증

총괄은 판정 기준을 결과 확인 전에 기록하고, 구현자가 제출한 커밋과 동일한 버전을 ChatGPT(Codex)가 독립 리뷰·재현하도록 한다. 검증 기록에는 커밋, 명령, 결과, 미실행 사유를 남긴다. 실전 전환과 긴급 중단 후 재개는 대표 승인 사항이다.
