# 텔레그램 알림 준비 (대표 결정 2026-11-27, D-052 §7.8)

> 작성: 프로그램 생성팀. 이 문서는 **봇을 만들고 키를 저장하는 준비 단계**까지만 다룹니다. 알림을 보내는 프로그램은 D-049 2단계 착수 승인 뒤에 만듭니다.
> **봇 토큰은 비밀번호와 같습니다.** 채팅창·문서·저장소·스크린샷 어디에도 붙여 넣지 말고, 아래 5단계의 키 파일에만 넣으세요.

## 1. 휴대폰에 텔레그램 설치·가입 (5분)
앱스토어/플레이스토어에서 **Telegram** 을 설치하고 전화번호로 가입합니다.

## 2. 봇 만들기 (BotFather)
1. 텔레그램 검색창에 `@BotFather` 를 입력합니다. **파란 체크 표시**가 있는 공식 계정을 엽니다.
2. `시작`(또는 `/start`)을 누른 뒤 `/newbot` 을 보냅니다.
3. 봇 이름을 보냅니다. 예: `주식왕 알림`
4. 봇 아이디를 보냅니다. 반드시 `bot` 으로 끝나야 하고 남과 겹치면 안 됩니다. 예: `stockking_alert_7391_bot`
5. BotFather 가 `123456789:AAH...` 형태의 **토큰**을 보내 줍니다. 다음 단계에서 쓰니 화면만 열어 둡니다(복사해 다른 곳에 저장하지 않음).

## 3. 내 봇과 대화 시작
BotFather 메시지의 `t.me/stockking_alert_..._bot` 링크를 누르고 → `시작` → 아무 글자(예: `hi`)를 한 번 보냅니다.
(이걸 해야 봇이 대표님께 메시지를 보낼 수 있습니다.)

## 4. 내 대화방 번호(chat_id) 확인 — 대표 PC 브라우저
주소창에 아래를 입력합니다(`<토큰>` 자리에 2단계 토큰을 붙여 넣음):
```
https://api.telegram.org/bot<토큰>/getUpdates
```
나온 글자 중 `"chat":{"id":` 뒤의 숫자(예: `987654321`)가 **chat_id** 입니다.
- `"result":[]` 처럼 비어 있으면 3단계의 `hi` 를 다시 보내고 새로고침합니다.
- 확인한 뒤 브라우저 방문 기록에서 이 주소를 지워 주세요(토큰이 주소에 들어 있음).

## 5. 키 파일에 저장 (PowerShell)
알림은 모의·실전 두 계좌가 함께 쓰므로, 계좌 키 파일과 따로 **알림 전용 파일**에 저장합니다(총괄 결정 §7.9).
```powershell
New-Item -ItemType Directory -Force "$env:APPDATA\stockking" | Out-Null
notepad "$env:APPDATA\stockking\notify.env"
```
메모장에 두 줄을 넣고 저장합니다(따옴표 없이):
```
TELEGRAM_BOT_TOKEN=2단계에서_받은_토큰
TELEGRAM_CHAT_ID=4단계에서_확인한_숫자
```
그다음 본인 계정만 읽도록 권한을 잠급니다:
```powershell
icacls "$env:APPDATA\stockking\notify.env" /inheritance:r /grant:r "$($env:USERNAME):(R,W)"
```
▶ `처리된 파일: 1` 이 나오면 끝입니다.
- 이 파일에는 텔레그램 두 줄만 넣습니다. KIS 키를 넣으면 프로그램이 실행을 거부합니다.
- 이미 `stockking\live\secrets.env` 에 텔레그램 줄을 넣으셨다면 그 두 줄을 `notify.env` 로 옮겨 주세요.
- 이 폴더는 OneDrive 밖(`%APPDATA%`)이라 클라우드로 복사되지 않습니다.

## 6. 안전 수칙
- 토큰이 새었다고 생각되면 BotFather 에서 `/revoke` → 새 토큰을 받아 5단계 파일만 고칩니다.
- 봇을 단체방에 초대하지 않습니다(BotFather `/setjoingroups` → `Disable` 권장).
- 프로그램이 보내는 알림에는 계좌번호·금액·키가 들어가지 않습니다(예: `[주식왕] 15:20 실계좌 점검 주문 매도 미체결 1주 — 확인 필요`).

## 7. 프로그램 쪽 (2단계에서 구현 예정)
- `stockking.notify.telegram`: 표준 라이브러리 HTTPS 1회 전송, 실패해도 주문·차단 동작은 그대로(실패는 감사 로그·콘솔).
- 시험 명령 `python -m stockking.ops.notify --test` 로 휴대폰 도착을 확인한 뒤 운용에 넣습니다.
- 알림 대상(총괄 결정 §7.9): 실전은 킬스위치·KILL_ALL 발동/해제, 손실 한도 도달, 시작 차단, L_TECH 경보. 모의는 킬스위치·KILL_ALL 만 `[모의]` 표시로. 같은 사건은 한 번만 보냅니다.
