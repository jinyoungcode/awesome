# 백테스트 엔진 MVP 범위 (1차 과업 #5)

> 구현: `src/stockking/backtest/` · 테스트: `tests/test_backtest.py`

## 1. MVP 포함 (구현 완료)

| 항목 | 내용 |
|---|---|
| 데이터 | 일봉(OHLCV), 다종목, 수정주가 전제. OHLC 정합성·음수 거래량 검증 |
| 신호→체결 | **D일 종가 신호 → D+1일 시가 체결** (look-ahead 차단), 매도 먼저 처리 후 매수 |
| 체결 가정 | 시가 ± 슬리피지(bp), 전량 체결, 거래량 0(거래정지)이면 미체결·폐기 |
| 비용 | 매수·매도 수수료, 매도세(거래세+농특세 합산), 원 미만 절사. **기본값 없음 — 회계팀 확정값 주입**. 미확정이면 결과에 경고 |
| 리스크 | 실전과 **동일한 RiskGate** 적용, 거부 내역·킬스위치 발동 횟수 리포트 |
| 지표 | 총수익률, CAGR, MDD, 샤프(무위험 0), 거래수, 승률, 손익비(Profit Factor), 평균 손익, 연 회전율, 총 수수료·세금 |
| 실행 | `python -m stockking.backtest --csv ... --commission ... --sell-tax ... --slippage-bps ... --source ...` |

## 2. MVP 제외 (P2 이전 추가 예정)

| 우선 | 항목 | 이유 |
|---|---|---|
| 높음 | 상장폐지 종목 처리(생존편향) | 자료수집팀 데이터 규격 확정 필요 |
| 높음 | 가격제한폭·상한가 미체결, 호가단위(틱) 반올림 | 체결 현실성 |
| 높음 | 거래량 대비 체결 한도(참여율 상한) | 소형주 과대평가 방지 |
| 높음 | 워크포워드·학습/검증 기간 분리 실행기 | 매매팀 과최적화 방지 규칙 |
| 중간 | 분할/배당 이벤트, 배당소득 반영 | 수정주가 정책에 따라 |
| 중간 | 벤치마크(KOSPI 등) 대비 지표, 월별 수익표, 리포트 HTML | 3자 검토용 |
| 중간 | 지정가 미체결(대기 주문), 분봉 백테스트 | 데이·스윙 전략 확정 시 |
| 낮음 | 다중 전략 동시 운용, 포트폴리오 리밸런싱 | P5 |

## 3. 백테스트 vs 모의투자 괴리 관리

P3 Gate 기준("백테스트 대비 괴리 허용 범위 이내")을 위해 같은 기간 백테스트와 모의투자 체결 로그를 비교하는 리포트를 P3 착수 전 구현한다. 비교 항목: 체결가 차이(슬리피지 실측), 미체결 건수, 일별 수익률 상관.
