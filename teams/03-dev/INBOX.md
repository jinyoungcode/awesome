### DATA-REQ-001 수집 파이프라인 요구사항 (자료팀 → 프로그램팀)
근거 문서: `teams/02-data/SOURCES.md`, `DATA_DICTIONARY.md`, `QUALITY.md`
1. **원천별 수집기**: KRX Open API(일봉·지수·종목정보), DART Open API(공시·재무·주요사항), 증권사 API(실시간·분봉), KRX 정보데이터시스템(지수 구성종목·상폐·관리 이력 — 소량/수동 허용).
2. **저장 계층 분리**: `raw`(원천 응답 그대로, append-only) → `clean`(DATA_DICTIONARY 스키마) → `derived`(수정계수 등). raw는 절대 덮어쓰지 않음.
3. **식별자**: PK는 `isin`. `ticker`는 재사용될 수 있음. DART 조인은 `corp_code`.
4. **수정주가**: 저장하지 말고 원주가 × `adj_factor`(버전 관리)로 조회 시 계산. 증권사 수정주가에 의존 금지.
5. **스케줄 (KST, 거래일)**: 08:00 종목마스터·캘린더 / 장중 실시간 시세 / 15:40 당일 분봉 확정 / 18:00 일봉·시장조치 / 18:30 수급 / 20:00 공시·재무·기업이벤트 / T+1 08:00 일봉 재수집(정정 반영).
6. **호출 제한 준수**: 원천별 rate limiter + 지수 백오프 재시도 + 일 쿼터 카운터. 한도는 설정 파일로 (수치는 SOURCES.md ⚠ 재확인 후 확정).
7. **품질 점검 훅**: 적재 직후 QUALITY.md 점검 실행, BLOCK 시 적재 중단 + 알림, 일일 품질 리포트 자동 생성.
8. **재현성**: 모든 행에 `source`, `collected_at`, `batch_id`. 특정 `batch_id` 기준 과거 상태 재구성 가능해야 함.
9. **백필**: 일봉 2011-01~, 재무 2015~ 초기 백필 작업을 쿼터 내로 분할 실행 (재시작 가능, idempotent).
10. **보안·약관**: API 키는 환경변수/시크릿 저장소. 수집 데이터는 **공개 저장소에 커밋 금지**(시세 재배포 금지 약관). 저장소에는 스키마·코드만.
11. **분봉 조기 적재**: 매매팀 결정 전이라도 유니버스 분봉 일일 적재를 먼저 켜 두기를 권고 (무료 분봉 장기 이력은 사후에 구할 수 없음).
