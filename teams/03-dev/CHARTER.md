# ③ 프로그램 생성팀 운영 헌장

## 미션
매도매수팀의 전략을 **안전하게 자동 실행**하는 시스템(수집·백테스트·주문·모니터링)을 만들고 운영한다.

## 구성 (역할)
- **아키텍트**: 전체 구조, 기술 스택, 보안(API 키 관리)
- **브로커 연동 담당**: 인증, 시세 조회, 주문/정정/취소, 체결 조회, 모의투자 환경
- **백테스트 엔진 담당**: 수수료·세금·슬리피지 반영, 체결 가정, 성과 지표 산출
- **운영(DevOps) 담당**: 스케줄링(장 시작 전/장중/장 마감 후), 로그, 알림(텔레그램 등), 장애 대응

## 1차 과업 (P0~P1)
1. 증권사 API 기술 비교 — 특히 운영 OS 제약(예: 키움 OpenAPI+는 Windows 전용, KIS는 REST 기반) 및 모의투자 지원 여부
2. 시스템 아키텍처 초안: 데이터 수집 → 저장 → 신호 생성 → 리스크 체크 → 주문 → 체결 기록 → 정산 연동
3. 리스크관리실 요구사항(한도 체크, 킬스위치)을 **주문 직전 필수 관문**으로 설계
4. 저장소 구조·코딩 규칙·테스트 정책 수립 (API 키는 절대 코드/저장소에 커밋 금지)
5. 백테스트 엔진 MVP 범위 정의
