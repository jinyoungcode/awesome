# 월간 결산 보고서 — YYYY년 MM월

> 작성: ⑤ 총무 회계팀 / 작성일: YYYY-MM-DD
> 보고 대상: 대표, 총괄운영팀 (사본: 리스크관리실, 매도매수팀)
> 단계: 모의 / T0(10만 원) / T1 / T2 / T3 / T4 (해당 단계 표시)
> 계좌 구분: **실전(`mode=live`, 주문 ID `LV-`)만 성과·세금·자금 집계 대상**이다. 병행 모의(`mode=paper`, `PP-`, D-049)는 §2-3의 체결 차이 비교에만 쓴다.
> 집계 기준: **자동매매(`book=AUTO`)가 본 보고 대상**이다. 대표 수동 매매(`MANUAL`)는 §2-1에 따로 적는다(D-029). 점검용 주문(`reason_code=T_TECH`, D-027)은 전략 성과에서 뺀다.
> 원본 데이터: `ledger/<mode>/<YYYY>/` — 이 보고서의 모든 숫자는 장부에서 다시 계산할 수 있어야 한다.
