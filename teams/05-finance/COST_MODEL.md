# 거래 비용 모델 (Cost Model) v0.1

> 작성: ⑤ 총무 회계팀 / 2026-11-23
> 용도: 백테스트·모의투자·실전 정산에 **공통으로 쓰는 비용 수치**. 프로그램팀은 이 문서의 '백테스트 적용값'을 설정값(config)으로 구현하고, 하드코딩하지 않는다.
> 상태: **v0.1 — 세율은 확인 완료 / 증권사 수수료는 계좌 개설 시 공식 수수료표로 최종 확정 필요**

## 0. 출처 등급 표기

| 등급 | 의미 |
|---|---|
| **A** | 법령·정부 발표·증권사 공식 페이지에서 직접 확인 |
| **B** | 2개 이상 언론/증권사 안내 보도에서 일치 확인(법령 원문 미열람) |
| **C** | 블로그·비교사이트 등 2차 자료. 확정 전 공식 확인 필수 |

> 참고: 이번 작업 환경은 네트워크 정책상 웹페이지 원문을 직접 열 수 없어, 웹 검색 결과(발췌)로 확인했다. 따라서 대부분 B 등급이다. **실전(P4) 전 법령 원문·증권사 수수료표로 A 등급 재확인**을 정산 체크리스트에 넣는다.

### 2-2. 판단
- 이벤트 수수료(0.003%대, 기간 한정)는 **백테스트에 쓰지 않는다.** 이벤트가 끝나면 기본 요율로 돌아가므로, 기본 요율로 수익이 나는 전략만 채택해야 한다.
- 두 후보 모두 기본 요율이 **편도 약 0.015%** 수준이다. 비용만으로는 증권사 선정에 결정적인 차이가 없다. 선정은 API 안정성·운영 OS·모의투자 지원(프로그램팀 판단)을 우선하는 것이 맞다는 것이 회계팀 의견이다.

## 3. 백테스트 적용값 (프로그램팀·매매팀 전달용)

> 원칙: **보수적으로(비용을 넉넉하게)** 잡는다. 실제보다 비용을 적게 잡은 백테스트는 실전에서 반드시 무너진다.

```yaml
# cost_model v0.1 (2026-11-23, 총무 회계팀)
commission:
  buy_rate:  0.00015      # 0.015% — 위탁수수료(유관기관 제비용 포함으로 간주, 보수적 반올림)
  sell_rate: 0.00015      # 0.015%
  min_fee_krw: 0          # 온라인 최소수수료 없음 가정 (증권사 확정 시 갱신)
  rounding: floor_krw     # 원 미만 절사 가정 — 증권사 확정 시 갱신
sell_tax:                 # 매도금액 x 세율, 매도 시에만
  schedule:               # 양도일(체결일 기준 T+2 결제일) 기준. 시장별 동일
    - {from: "2000-01-01", to: "2019-06-02", kospi: 0.0030, kosdaq: 0.0030}  # 잠정
    - {from: "2019-06-03", to: "2020-12-31", kospi: 0.0025, kosdaq: 0.0025}  # 잠정
    - {from: "2021-01-01", to: "2022-12-31", kospi: 0.0023, kosdaq: 0.0023}  # 잠정
    - {from: "2023-01-01", to: "2023-12-31", kospi: 0.0020, kosdaq: 0.0020}  # 잠정
    - {from: "2024-01-01", to: "2024-12-31", kospi: 0.0018, kosdaq: 0.0018}  # 잠정
    - {from: "2025-01-01", to: "2025-12-31", kospi: 0.0015, kosdaq: 0.0015}
    - {from: "2026-01-01", to: null,         kospi: 0.0020, kosdaq: 0.0020}
  rounding: floor_krw     # 원 미만 절사 가정
slippage:                 # 세금·수수료가 아님 — 매매팀 결정 사항 (회계팀 제안값)
  per_side: 0.0005        # 0.05% / 편도 (KOSPI200 등 대형주 기준 제안). 소형주·분봉 전략은 상향
dividend_withholding: 0.154
capital_gains_tax: 0      # 소액주주 국내 상장주식 장내거래 = 비과세
```
