## 1. 첫 체결일 수수료 확정 절차 (C-2)

> **D-042 반영:** 1일차(11/26)의 1주 주문·취소(`connect_check --order`)는 체결이 없을 수 있다. 그래서 **첫 실측은 첫 체결이 생긴 날**에 한다. 예상은 **2일차(11/27) S02 체결**이다. 1일차에 1주 주문이 체결되면 그날 실측한다. 아래 '첫 체결일'은 이 날을 뜻한다.

### 1-0. 원칙
- 장부의 수수료·세금은 **증권사가 실제로 뗀 금액**이 기준이다. COST_MODEL 추정치는 체결내역에 값이 없을 때만 임시로 쓰고 `note`에 "추정"을 남긴다(프로그램팀 `ledger.py` 구현과 같음).
- ⚠ **모의투자 계좌의 수수료·세금은 모의 시스템이 정한 값이다. 실계좌 요율과 같다는 보장이 없다.** 그래서 3일 모의에서 확정하는 것은 **① 장부 계산 로직(원 단위 처리·대사 공식)이 맞는지**와 **② 모의 계좌의 실제 차감액**이다. 실계좌 요율은 대표 확인(C-8)과 T0 1일차에 같은 절차를 한 번 더 거쳐 확정한다.

### 1-1. 첫 체결일(예상 11/27) 장 마감 후 순서

| 단계 | 할 일 | 담당 | 산출물 |
|---|---|---|---|
| ① | `ledger_close --close` 실행 → trades/positions/daily_pnl 생성 | 프로그램 | `var/ledger/paper/2026/*.csv` |
| ② | 한투 모의 **체결내역**(주문체결조회)에서 체결 건별 수수료·제세금 값이 있는지 확인. 있으면 장부 값과 1원 단위로 비교 | 프로그램 → 회계 | 건별 비교표(아래 1-2) |
| ③ | 건별 값이 없으면 **예수금 역산**: `실제 비용 합계 = Σ매도 체결금액 − Σ매수 체결금액 − (D+2 예수금 변화)`. 이 값과 장부 추정 비용 합계를 비교 | 회계 | 역산표 |
| ④ | 차이가 있으면 원인 판별: (a) 요율 차이 (b) 원 미만 처리 차이(절사·반올림·10원 단위) (c) 거래세 적용 여부 (d) 최소수수료 (e) 그 밖(장부 오류) | 회계 | 원인 메모 |
| ⑤ | (a)~(d)이면 모의 전용 비용값을 확정하고 이후 거래일 장부에 적용. 첫 체결일 행은 실측값으로 고치고 `note=실측(C-2)`, `recon_status=RESOLVED` | 회계 → 프로그램 | 모의 비용값 확정 메모 |
| ⑥ | (e)이면 장부 로직 오류 → 프로그램팀 수정 요청. 그날은 `DIFF` 유지 | 회계 → 프로그램 | INBOX 요청 |
| ⑦ | 결과를 COST_MODEL C-2 행에 기록("모의 계좌 실측: 요율 x%, 처리 방식 y"). **실계좌 요율로 쓰지 않는다** | 회계 | COST_MODEL 갱신 |

### 1-2. 건별 비교표 (첫 체결일, 체결 건마다 1행)

| trade_id | 매매 | 체결금액 | 장부 수수료(추정) | 실제 수수료 | 차이 | 장부 거래세(추정) | 실제 거래세 | 차이 | 실효 수수료율 = 실제 ÷ 체결금액 | 원 미만 처리 추정 |
|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | | 절사 / 반올림 / 10원 |

**원 미만 처리 판별법:** `체결금액 × 요율`을 계산해 소수점 아래를 확인한다. 실제 값이 내림이면 절사, 0.5 기준이면 반올림이다. 10원 단위로 끊기면 10원 미만 절사다. 체결 2건 이상에서 같은 방식이 나오면 확정한다.

### 1-3. C1(대사 100%) 판정 기준 — **총괄 확정 (2026-11-25)**
**첫 체결일**은 다음 세 조건을 **모두** 만족할 때만 `RESOLVED`(통과)로 본다. (D-042로 일정이 바뀌어 총괄 기준의 '1일차'를 '첫 체결일'로 적용 — 총괄 확인 완료, 2026-11-25)
1. 현금 차이가 **건별로** 수수료·제세금의 추정치와 실측치 차이만으로 설명된다.
2. 실측값으로 바꾼 뒤 차이가 **1원 단위로 0원**이다.
3. **수량(주식 수) 차이가 0건**이다.

- 수량 차이가 있거나, 원인을 설명할 수 없는 차이가 1원이라도 남으면 **미통과**다.
- 결산 요약(§2의 5-1)에 **교체 전후 값과 근거(체결내역 화면 또는 예수금)** 를 남긴다.
- **체결이 없는 날**(예: 1일차 주문·취소만)은 현금·수량 차이가 처음부터 0원·0주여야 통과다.
- **첫 체결일 이후의 날은 실측 요율로 처음부터 0원이어야 통과**다(RESOLVED 불가).

### 1-4. 첫 체결일 이후
- 첫 체결일 확정값으로 장부를 만들고, 마감 후 `broker_equity_krw`와 `end_equity_krw`의 차이가 **0원**인지 확인한다.
- 0원이 아니면 1-1 ④~⑥을 반복한다. 확정 이후에 수수료 차이가 다시 나면 확정값이 틀린 것이므로 C-2를 다시 연다.
