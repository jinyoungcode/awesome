# 일봉 데이터 인터페이스 확정안 — S02 스윙 검증용 (v1.0)

> 작성: ② 자료 수집팀 / 2026-11-24 — ③ 프로그램팀 요청(2026-11-23, 2026-11-24) 회신
> 우선순위: D-020 S02(1~5거래일 스윙) 모의 검증용 **최우선**. D-033에 따라 T0 실전은 **국내 S02만** → 국내 일봉을 먼저 공급하고, 미국 일봉·환율은 D-018/D-035 일정에 맞춰 공급

## 1. 일봉 CSV (프로그램팀 제안 수용 + 3개 열 추가)

```
date,symbol,currency,open,high,low,close,volume,value,adj_version
2025-03-04,005930,KRW,57000,57900,56800,57600,12345678,710000000000,af-v1
2025-03-04,AAPL,USD,235.81,238.12,234.50,237.30,45678901,10839000000.00,af-v1
```

| 열 | 규칙 |
|---|---|
| `date` | `YYYY-MM-DD`, 해당 시장 현지 거래일 (미국은 미국 날짜) |
| `symbol` | 국내: 6자리 단축코드(앞자리 0 유지, **문자열**로 읽을 것) / 미국: 티커(예: `AAPL`, `BRK.B`) |
| `currency` | `KRW` / `USD` (D-006 요청 반영) |
| `open`~`close` | **수정주가**. KRW는 원 정수, USD는 소수 둘째 자리까지(수정 후 4자리 허용) |
| `volume` | 수정거래량, 정수 |
| `value` | **거래대금 (원천 공표값, 수정 없음)**. KRW 원 정수 / USD 소수. S02 ADV20 계산은 종가×거래량 근사 대신 이 값을 사용 (프로그램팀 2026-11-24 S02 확인 요청 ① 회신) |
| `adj_version` | 수정계수 버전. 같은 버전이면 같은 값 보장 (재현성) |

- 수정 기준: **분할·병합·무상증자·감자 등 주식수 이벤트만 반영, 현금배당 미반영(가격수익)**. 배당 포함 총수익 계수는 필요 시 `adj_version=af-v1-tr` 별도 파일
- 내부 저장은 원주가 + 수정계수(`DATA_DICTIONARY.md` §2·§4)이고, 이 CSV는 그로부터 생성하는 **내보내기 뷰**다. 계수가 바뀌면 과거 값도 바뀌므로 백테스트 결과에 `adj_version`을 반드시 기록

## 2. 거래정지일 표기 (회신)
- 행을 **남긴다**. `volume=0`, `open=high=low=close=직전 거래일 종가`
- 별도로 `halts.csv` (`date,symbol,status`) 제공 → 엔진은 정지일 주문 불가 처리 (volume=0만으로 판단하지 말 것: 극소 거래 종목과 구분 불가)
- 상장폐지: 마지막 거래일(정리매매 포함 여부는 `delistings.csv`의 `last_regular_date`, `last_trade_date`로 구분)까지 행 존재, 이후 행 없음

## 3. 환율 CSV (D-006 회신)
```
date,usdkrw
2025-03-04,1458.20
```
- 출처: 한국은행 ECOS 원/달러 **매매기준율** (한국 날짜 기준)
- 사용 규칙: 미국 거래일 D의 평가·손익은 **한국 날짜 D의 매매기준율**로 환산 (D+1 값은 미국 장 마감 후 고시 → look-ahead 금지)
- 한국 휴일로 고시가 없으면 직전 고시값 사용 (forward fill), 채운 값은 `fx_filled.csv`에 기록

## 5. 샘플 데이터 (프로그램팀 요청, 기한 2026-12-11)
- 구성: 국내 10종목 × 2019-01 ~ 현재 (상장폐지 2종목, 거래정지 이력 2종목, 액면분할 1종목 포함) + 미국 5종목(분할 이력 포함)
- 전제: **대표 KIS 가입·KRX Open API·DART 인증키 발급 후** 수집 (대표 2026-11-25 KIS 가입 예정). ECOS(환율)는 미국 단계 착수 시
- 순서: 국내 10종목 먼저(12-11 기한), 미국 5종목은 D-035 검증 구간 일정에 맞춤
- `calendar.csv`(KR 휴장일)는 장부 결제일(T+2) 계산에도 쓰이므로 국내 샘플과 함께 우선 전달
- 전달 방식: 저장소 커밋 금지(재배포 금지 약관). `STORAGE.md`의 비공개 저장소 경로로 전달. 저장소에는 생성 스크립트와 체크섬만
