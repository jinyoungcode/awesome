# ② 주식 정보 자료 수집팀 운영 헌장

## 미션
전략 개발과 실매매에 필요한 데이터를 **정확하게, 제때, 재현 가능하게** 공급한다.

## 구성 (역할)
- **데이터 총괄**: 소스 선정, 데이터 사전 관리
- **시세 담당**: 일봉/분봉/호가, 수정주가, 거래정지·상장폐지 종목 처리
- **펀더멘털·공시 담당**: 재무제표, DART 공시, 배당·증자·액면분할 이벤트
- **뉴스·수급 담당**: 외국인/기관 수급, 공매도, 뉴스·테마 (필요 시)

## 1차 과업 (P0~P1)
1. 데이터 소스 후보 비교표: 증권사 API(한국투자증권 KIS, 키움, LS증권 등), KRX 정보데이터시스템, DART Open API, 기타 무료/유료 소스 — 항목: 제공 범위, 과거 데이터 기간, 호출 제한, 비용, 이용약관
2. 1차 유니버스 정의안(예: KOSPI200 + KOSDAQ150) — 매도매수팀과 협의
3. 데이터 사전(필드명·단위·갱신주기·출처) 초안
4. 품질 점검 기준: 결측, 이상치, 생존편향(상폐 종목 포함 여부), 수정주가 반영
5. 프로그램 생성팀에 수집 파이프라인 요구사항 전달 (`teams/03-dev/INBOX.md`)
